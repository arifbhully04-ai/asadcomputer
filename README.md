# আসাদ কম্পিউটার ও ভূল্লী ডিজিটাল পোস্ট অফিস
### Asad Computer & Bhulli Digital Post Office Management Web Application

চাকরির নির্ভুল অনলাইন আবেদন ও আধুনিক কম্পিউটার প্রশিক্ষণ কেন্দ্র — ভূল্লী, ঠাকুরগাঁও।

---

## 🌟 প্রধান বৈশিষ্ঠ্যসমূহ (Key Features)

1. **মাল্টি-পেজ / ট্যাব আর্কিটেকচার (Multi-Page Navigation):**
   - **হোম পেজ:** প্রতিষ্ঠানের পরিচিতি, নোটিশ টিকার, কম্পিউটার ল্যাবের চলমান ছবি ও প্রতিষ্ঠানের ৩ জন দায়িত্বশীল কর্মকর্তার পরিচিতি।
   - **চাকরির বিজ্ঞপ্তি (Job Circulars):** সরকারি, ব্যাংক, ডিফেন্স ও বেসরকারি চাকরির সার্কুলার ফিল্টার ও বিস্তারিত দেখার ব্যবস্থা।
   - **কম্পিউটার কোর্স (Computer Courses):** বেসিক অফিস অ্যাপ্লিকেশন, গ্রাফিক্স ডিজাইন, হার্ডওয়্যার ও নেটওয়ার্কিং কোর্সের সিলেবাস ও অনলাইনে ভর্তি আবেদন।
   - **অনলাইন সেবাসমূহ (Online Services):** পাসপোর্ট, জাতীয় পরিচয়পত্র (NID), পুলিশ ক্লিয়ারেন্স, ড্রাইভিং লাইসেন্স, বিদ্যুৎ বিল পেমেন্ট ইত্যাদি।
   - **ইউজার / শিক্ষার্থী ড্যাশবোর্ড (Student Portal):** লগইন/রেজিস্ট্রেশন, আবেদন ট্র্যাকিং, কোর্স স্ট্যাটাস এবং অফিশিয়াল আবেদন কপি প্রিন্ট।
   - **এডমিন কন্ট্রোল প্যানেল (Admin Panel):** চাকরির বিজ্ঞপ্তি পোস্ট, প্রার্থীর আবেদন প্রসেসিং, শিক্ষার্থীর তথ্য ভিউ, স্ট্যাটাস আপডেট, টাকা জমার এন্ট্রি ও রসিদ ব্যবস্থাপনা এবং ডিজিটাল আইডি কার্ড প্রিন্ট।

2. **প্রতিষ্ঠানের তথ্য ও যোগাযোগ:**
   - **ঠিকানা:** বটতলা, ভূল্লী বাজার-৫১০০, ভূল্লী, ঠাকুরগাঁও।

## 🚀 গিটহাবে আপলোড করার নিয়ম (GitHub Upload Guide)

### অপশন ১: গিট কমান্ড লাইনের মাধ্যমে (Recommended Git CLI)

আপনার কম্পিউটারের টার্মিনাল বা কমান্ড প্রম্পটে (Command Prompt / Git Bash) নিচের কমান্ডগুলো একটার পর একটা রান করুন:

```bash
# ১. গিটহাবে (github.com) লগইন করে "New repository" তৈরি করুন (যেমন নাম: asad-computer)
# ২. তারপর আপনার প্রোজেক্ট ফোল্ডারে টার্মিনাল ওপেন করে লিখুন:

git remote add origin https://github.com/<আপনার-গিটহাব-ইউজারনেম>/asad-computer.git
git branch -M main
git push -u origin main
```

*(যদি আগে কোনো রিমোট যুক্ত করা থাকে, তবে `git remote set-url origin https://github.com/<আপনার-গিটহাব-ইউজারনেম>/asad-computer.git` ব্যবহার করুন)*

---

### অপশন ২: গিটহাব ওয়েবসাইটে সরাসরি ফাইল আপলোড (GitHub Web Upload)

1. [GitHub](https://github.com) এ লগইন করুন।
2. **"New repository"** বাটনে ক্লিক করে রিপোজিটরির নাম দিন: `asad-computer` (Public বা Private সিলেক্ট করুন)।
3. রিপোজিটরি তৈরি হলে পেজে **"uploading an existing file"** লিংক দেখতে পাবেন, সেখানে ক্লিক করুন।
4. এই প্রজেক্টের ফাইলগুলো (বা `asad-computer-project.zip` আনজিপ করে সব ফাইল) ড্র্যাগ করে গিটহাবে ছেড়ে দিন।
5. নিচে **"Commit changes"** এ ক্লিক করলেই সাথে সাথে আপনার কোড গিটহাবে সেভ হয়ে যাবে!

## 🛠️ লোকাল মেশিনে রান করার নিয়ম (How to Run Locally)
